# 📸 Galería de Fotos

Coloca aquí las fotos de Diana y Oscar para la sección de galería.

## Formatos soportados
- JPG / JPEG
- PNG
- WebP

## Cómo agregar fotos

1. Sube tus fotos a esta carpeta (`assets/img/`)
2. En `index.html`, busca la sección **GALERÍA** (línea ~216)
3. Reemplaza los placeholders con tus imágenes:
   ```html
   <img src="assets/img/photo1.jpg" alt="Diana y Oscar" style="width: 100%; height: 100%; object-fit: cover;">
   ```

## Recomendaciones

- **Tamaño**: idealmente entre 500-2000px de ancho
- **Peso**: no más de 500KB por foto (comprime antes de subir)
- **Proporción**: cualquiera funciona gracias a `object-fit: cover`

¡Las fotos harán tu invitación única! 💕
